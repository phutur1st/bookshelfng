The optional Library OPF provider now exports ebook metadata without Calibre,
alongside its existing audiobook sidecars. Exports include available narrator
credits. Existing provider configurations retain their identity. Select OPF
before embedded tags in compatible readers and review older sidecars before
backfilling an existing library. Ebook and audio file contents are unchanged.
